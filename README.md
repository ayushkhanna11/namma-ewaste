## 📌 Project Overview

Bengaluru generates over **100,000 tonnes of e-waste annually**, but less than 10% is formally recycled. Major challenges include consumer hoarding due to data privacy fears, informal sector dominance, and a lack of accessible, decentralized drop-off infrastructure. Individual doorstep pickups are logistically inefficient and create high transportation emissions.

**Namma E-Waste** solves this bottleneck by shifting the paradigm from **individual collection to community threshold aggregation**. Household units and corporate spaces log their discarded electronics onto a localized dashboard. Once a hub reaches a minimum weight threshold (60 kg for societies, 100 kg for tech parks), an automated alert triggers a bulk pickup, drastically reducing carbon emissions and logistical overhead.

*This project is being developed as a student-led prototype for the **GYCN SDG Summit in Malaysia**.*

---

## ✨ Key Features

- **🏢 Multi-Hub Management:** Register and switch between different residential societies (e.g., Koramangala) and corporate tech parks (e.g., Whitefield / Manyata).
- **📝 Individual Logging System:** Track household or office contributions by unit number, device category, quantity, and weight.
- **📊 Real-time Analytics:** Visual progress bars track cumulative hub accumulation toward target weight thresholds.
- **🚚 Simulated Dispatch Alerts:** Automatically triggers a simulated collection van alert with a unique dispatch ticket ID upon reaching capacity targets.
- **🌱 Eco-Tech UI/UX:** Styled using modern, responsive design principles with live indicators and intuitive layouts.
